# MatchPulse-AI

منصة تحليل احتمالي لمباريات كرة القدم، انطلقت من فكرة دمج جدول مباريات حقيقي مع تحليل جماعي قابل للتفسير. لا يَعِد المشروع بدقة 100% ولا يقدم النتيجة على أنها ضمان؛ يعرض احتمالات ودرجة اكتمال البيانات ومنهج التحليل حتى يستطيع المستخدم تقييمها بوعي.

## ما تم بناؤه

تعرض الواجهة جدولًا لجميع المباريات التي يعيدها مصدر `football-data.org`، مع الموعد والبطولة والفريقين والحالة. لكل مباراة زر يفتح نافذة OBTA تعرض احتمالات فوز صاحب الأرض والتعادل وفوز الضيف، ودرجة الثقة النموذجية، ومصدر البيانات، وطريقة الحساب. الألوان الرياضية تعني: الأخضر اتجاه احتمالي أعلى، الأصفر احتمال متوسط، والأحمر احتمال منخفض أو عامل مخاطرة؛ ولا تعني نتيجة مؤكدة.

عند عدم ضبط مفتاح المصدر لا تعرض الواجهة مباريات وهمية، بل تظهر حالة واضحة تطلب إعداد المصدر. وعند فشل الشبكة، تبقى الصفحة قابلة للاستخدام وتوضح أن البيانات غير متاحة.

## التشغيل

```bash
cp .env.example .env
# ضع FOOTBALL_DATA_TOKEN في بيئة الخادم فقط
npm start
```

افتح `http://localhost:8787`. يوفر الخادم `GET /api/health` و`GET /api/matches?status=SCHEDULED`، ويخفي مفتاح المصدر عن المتصفح.

## الاختبارات

```bash
npm run check
npm test
```

## البيانات والمنهجية

يستخدم الإصدار الأول عقدًا مع مصدر بيانات خارجي رسمي من خلال `FOOTBALL_DATA_TOKEN`. لا توجد مباريات أو نتائج مزروعة داخل المشروع. طبقة الاحتمالات الحالية baseline تفسيرية وليست نموذجًا مدربًا على بيانات تاريخية؛ قبل تسمية النتائج بتوقعات إنتاجية ينبغي إضافة بيانات تاريخية مرخّصة، تقسيم زمني للتدريب والاختبار، معايرة احتمالات، وقياسات مثل Brier score وlog loss.

## الخصوصية والاستخدام المسؤول

لا يضع المشروع مفاتيح API في الواجهة أو Git. لا ينبغي استخدام الاحتمالات كضمان أو كأساس وحيد لقرار مالي أو مراهنة؛ النتائج الرياضية غير يقينية وقد تؤدي القرارات المبنية عليها إلى خسارة المال.
